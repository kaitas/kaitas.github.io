# yc26f — private drafts (not published)

This folder holds working documents that are **kept in the repository but excluded
from the published website**. The exclusion is configured in `_config.yml`:

```yaml
exclude:
  - yc26f
```

Because the whole `yc26f/` directory is excluded, Jekyll does not build or deploy
anything inside it. The files remain available to editors via the git repository only.

## Contents

- `aicu_yc_accomplishments.html` — Draft of the Y Combinator founder-profile
  "Accomplishments" answers for Akihiko Shirai / AICU (English submission text with
  Japanese editorial notes). Reference material; verify all figures, award years,
  patent counts, and official program names against primary sources before any
  external submission.
